# 更新履歴

## v1.3 — 持続的な指の動きで照準、瞬間的な指の伸びで射撃
- 照準を**人差し指の先（ランドマーク8）**に戻し、曲げた状態も伸ばした状態も連続追従
- 射撃を指先の**急速な伸長**から判定する `INDEX_FLICK` モードに変更
- 手全体の平行移動と指先の横移動は、基本的に射撃とみなさない
- 指を伸ばしたままでも照準を動かせるように、押しっぱなしの固定を廃止
- 発射瞬間のみ約85ms照準固定／クールダウンと指の戻しで誤連射防止
- しきい値調整（`-` / `=`）、命中補正（`A`）と練習モードを継続
- 以前の `INDEX_UP` 起動オプションは `INDEX_FLICK` の別名として認識
- 人工的な手の動きによる判定テストを追加、説明書とUI表示も更新

## v1.2 — 人差し指を上げて撃つ
- 人差し指を曲げてから上げる方式を追加
- 以前は人差し指の付け根で照準を動かしていた（v1.3で改善）
