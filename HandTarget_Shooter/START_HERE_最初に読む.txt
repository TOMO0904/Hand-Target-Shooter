RiG++ HAND TARGET SHOOTER v1.3 / Windows
=======================================

■ 起動：START_GAME_Windows.bat をダブルクリック

【新しい操作】
  人差し指を「ゆっくり・持続的」に動かす → 照準移動
  人差し指を「パッと素早く」伸ばす      → 1発射撃

  伸ばしたままでも照準を移動できます！
  指を少し戻してから素早く伸ばすと次の1発を撃てます。
  前の版と違い、照準は人差し指の付け根ではなく「指先」を追いかけます。

■ 起動直後は練習モード：的を3つ撃ってから本番へ

■ 困ったとき
  - : 発射を緩くする（繰り返し押せます）
  = : 発射を厳しくする
  A : 命中補正をHIGHにすると外れにくくなります
  C : 指をリラックスさせた状態で押す（任意の調整）
  M : 親指やピンチで撃つ方式にも切り替え可能

■ カメラ番号1：START_CAMERA1_Windows.bat
■ カメラなし：START_DEMO_Windows.bat（マウスで遊ぶ）

■ その他
  1 / 2 / 3 : 難易度変更
  R : 練習やり直し
  Space : 練習をクリアしたら本番開始
  Q / Esc : 終了

初回だけ必要なライブラリと手認識モデルをダウンロードします。
詳しくは README.md を参照してください。
